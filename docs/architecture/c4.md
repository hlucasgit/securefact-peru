## 3. Components — ElectronicDocuments (pipeline CPE)

```mermaid
flowchart LR
  A[External Request] --> B[Validation syntactic]
  B --> C[Canonical ElectronicDocument]
  C --> D[TaxEngine]
  D --> E[SUNAT Rules versionadas]
  E --> F[IUblDocumentGenerator]
  F --> G[IXmlSchemaValidator XSD]
  G --> H[IXmlBusinessRuleValidator]
  H --> I[IXmlSigner]
  I --> J[Packager ZIP]
  J --> K{ICpeSubmissionChannel}
  K --> K1[DirectSunatChannel]
  K --> K2[ThirdPartyPseChannel]
  K --> K3[ThirdPartyOseChannel]
  K --> K4[SandboxChannel]
  K --> K5[FutureSecureFactPseChannel · OwnPseMode=false]
  K1 & K2 & K3 & K4 --> L[CDR Parser]
  L --> M[State machine + History]
  M --> N[Outbox → Webhooks / PDF / Notifications]
```

Módulos (cada uno con `Contracts` público): Identity, Tenancy, Organizations, Catalogs, Customers, Products, Billing, TaxEngine, ElectronicDocuments, Certificates, Sunat (adapters), Gre, Notifications, Webhooks, Developers, Subscriptions, Resellers, WhiteLabel, Audit, Reporting.

## 4. Deployment (objetivo; en MVP basta una instancia por servicio)

```mermaid
flowchart TB
  subgraph Internet
    U[Clientes / SPA / Integradores]
  end
  U --> LB[Load Balancer + TLS]
  subgraph Cluster[Entorno Production]
    LB --> API1[API #1]
    LB --> API2[API #2]
    API1 & API2 --> PGP[(PostgreSQL primario)]
    PGP --> PGR[(Réplica / HA + PITR)]
    API1 & API2 --> RD[(Redis)]
    API1 & API2 --> OBJ[(Object Storage S3)]
    W1[Document Worker xN] --> PGP
    W1 --> OBJ
    W1 --> MQ[(RabbitMQ HA)]
    W2[Webhook / Notification Workers] --> MQ
    OBS[OpenTelemetry Collector → Prometheus/Loki/Tempo/Grafana]
  end
  W1 -->|egress controlado| EXT[SUNAT / PSE / OSE]
```

Entornos: Local (docker compose), Test, Staging, Production. Credenciales y certificados separados; la configuración por defecto de `Test` y `Local` solo admite `SandboxChannel` (ver ADR-006).
